# LearnKyrgyz

This repository holds **LearnKyrgyz**, a Duolingo-style app for learning Kyrgyz with a teacher app for classes, homework, exams and worksheets.

The code is on the `claude/erdan-offline-writing-app-7sgntw` branch, and GitHub Actions deploys it from there:

- https://learnkyrgyz.web.app (landing)
- https://studentlrnkyrgyz.web.app (students)
- https://teachlrnkyrgyz.web.app (teachers)
- Preview: https://erdanthecoder.github.io/copilot/

The `main` branch isn't used to build or deploy anything.
